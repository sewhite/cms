# cms
Some additional custom tools for Paratext 9. 

These are some tools I have develope using Claude to help Paratext 9 users with some specific problems.
- ApplyParagraphs2026  this tool adds paragraph markers to a Paratext project based on where these markers are found in a model project.
- LexiconReadable   this is an attempt to extract the Paratext interlinearizer data into a human readable web page that can be filtered either by glosses or by words in the source language. 

To use them, download the .cms file and the corresponding .py file and put them in the cms subfolder of your Paratext projects folder ("c:\\My Paratext 9 Projects" if you accepted the defaults.)
